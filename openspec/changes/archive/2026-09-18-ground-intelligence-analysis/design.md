## Context

The selected passages establish a narrow addition to the existing analytic spine. The repository already registers Heuer, SAT, and Lindsay; it needs only Clark and Cvetko-Davydiuk added to the register. The source-of-truth grid must move before affected skill prose, and `doctrine_source` may identify a real doctrinal dependency but must not attribute a grid-derived procedure to a book that does not prescribe it.

## Goals / Non-Goals

**Goals:**
- Ground the target-model/gap, human–automation, and access-versus-outcome boundaries in selected library sources.
- Make those boundaries observable in the grid and three existing skills.
- Preserve current grid rows, marks, skill bindings, and all existing procedures.

**Non-Goals:**
- Add a warning/PIR capability, a new skill, an agent, an agent-prompt rewrite, or a new automation mechanism.
- Attach Heuer or SAT as a blanket attribution to analytic techniques.
- Change any collection query, evidence-reading, or report-format procedure.

## Decisions

- Add `Clark` and `Cvetko-Davydiuk` under Analytic tradecraft in the register, because they are intelligence-analysis sources rather than primary cyber-operational frameworks.
- Put the source citations in the grid prose, then add `doctrine_source` only to `human-automation-teaming` and `outcome-judgement`, where the selected works support the skill's framing. `naming-the-gaps` remains grid-anchored because its method is procedural.
- Add narrowly worded sentences rather than changing any grid table row: the competency structure already has the required skills.

## Risks / Trade-offs

- Adding citations to a method detail would falsely assert that a source prescribed the repository's procedure. The change limits attribution to framing claims and keeps the existing grid anchors.
- Updating the generated map requires reproducing the prior model before rebuilding it; map drift is verified separately from the repository guard.
